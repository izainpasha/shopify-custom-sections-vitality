# Custom Shopify sections — Vitality Cycles

A set of custom Online Store 2.0 sections for a supplement brand's homepage, product and landing pages.

![Custom Shopify sections — Vitality Cycles](.github/screenshot.webp)

**Live site:** https://vitalitycycles.com  
**Portfolio:** https://izainpasha.github.io

## The problem
Vitality Cycles needed brand-specific homepage, product-page and landing sections that their team could rearrange in the theme editor.

## What I built
Around 25 custom sections (benefits, founder story, reviews, FAQ, product info, comparison and more) and supporting snippets, plus a script that generates page templates.

## Result
Pages assembled from reusable sections with editable settings instead of hard-coded layouts.

## Stack
Liquid · Online Store 2.0 · CSS · JavaScript
